# graduation-app
## 1. サービス概要（※最後に書いてOK）
---
トレ辞書は、筋肉トレーニングにおいてなにがどのような効果を体にもたらすかを伝えるアプリです。ユーザーが鍛えたい筋肉に応じて、AIによるトレーニング情報の提供から、ほかに同じようなトレーニングをしているか共有することでトレーニングを一人で行っているのではなく、いろんな人と一緒に行っている感覚を提供します。

## 2. このアイデアはどこから生まれたか

### 2-1. きっかけとなった体験・感情
学生時代から趣味としてジムでの筋トレを続けてきました。その中で、周りの人にも一緒にトレーニングしてほしいと思い声をかけましたが、長く続く人はほとんどいませんでした。

トレーニングには向き不向きがあると思います。ただ、続かない理由には「やっている種目の意味や効果がわからないこと」や「一緒に取り組む仲間がいないこと」もあるのではないかと考えました。実際に、目的を理解して取り組むことや、仲間がいることで、トレーニングはより楽しくなると思います。

そこで、条件を選ぶだけでおすすめのトレーニングとその効果がわかり、さらに他のユーザーの取り組みも見られるアプリがあれば、トレーニングを始めるきっかけや続けるきっかけを増やせるのではないかと考えました。

### 2-2. なぜそれが「気になった」のか

学生時代からトレーニングを続ける中で、しんどさや「またこれをやるのか」という気持ちを感じ、そのきつさに意義を見いだせないことがありました。一方で、動きの意味を理解して取り組んでいたときのほうが、トレーニングが続いた経験があります。

また、私は物事を無駄なく効率よく進めることを大切にしています。そのため、意味がわからないまま取り組むきつさは、効率化が進めば感じにくくなると考えました。そして効率化を進めるには、一つひとつの動きの意味やトレーニングの効果を理解することが必要です。それらを手軽に知ることができる本アプリを開発しようと考えました。

## 4. 想定ユーザーについて

### 4-1. 想定しているユーザー

年齢設定：
  - 年齢：30代　男性
  - 理由：30代は体力の衰えや体型の変化を実感しやすく、「何とかしなければ」と考え始める年代だからです。そのため、この時期に筋トレへ挑戦する人が多いと考えられます。まだ筋トレへの意識が高くない段階だからこそ、本アプリを通じて、筋トレに対する意欲を高めてもらいたいと考えました。

生活・状況設定：
  - 生活・状況：仕事に力を入れていた年代から少し余裕が生まれる年代
  - 理由：20代でキャリアの土台を築いた人が、30代になって生活に少しゆとりを持ち始め、「何か新しいことを始めたい」と考える世代を想定しています。ただし、そのゆとりは限られた時間です。本アプリでトレーニング内容を決める時間を短縮し、限られた時間を効率よく使えるようにします。
    
環境設定：
  - 環境：仕事が終わった後、自由時間でトレーニングすることを想定しています。
  - 理由：仕事後は、使える時間が限られているうえに疲れており、「今日は何をやろうか」と考えること自体が負担になりやすいからです。そのため、トレーニング中に種目選びで迷ったり、調べ直したりする時間を減らし、「なぜこの種目をやるのか」を理解したうえで、短時間でも納得して取り組める状況を想定しました。また、仕事後は「面倒だからやめておこう」と感じやすいため、理由が分かることで目的意識を持って続けやすくなると考えました。
---

### 4-2. 自分とユーザーの距離

- 過去の自分


理由：私自身が、トレーニングを「ただこなすだけ」になり、種目選びに迷って何をすればよいか分からなくなった経験があるからです。今の私は、トレーニングの意味を調べて理解しつつありますが、当時の私にはそれを知る手段がありませんでした。そのため、「あのとき理由が分かる仕組みがあれば迷わなかった」と思える、過去の自分のような人をユーザーとして想定しました。

### 4-3. 実際に使われる可能性について(需要・存在確認)

このアプリは、「実際に使う人がいそうか？」という視点で見たとき、どうでしょうか。

- まず最初に使ってくれそうな人は誰か？
  ・最初に使ってくれそうなのは、「過去の自分」のような人です。つまり、30代で体の衰えを感じて筋トレを始めたものの、種目選びに迷い、何をすればよいか分からなくなっている男性です。【身近な例:同僚・友人など】
- その人は、どんな場面でこのアプリを思い出すか？
  ・仕事後にジムや自宅でトレーニングを始める前、「今日は何をやろうか」と迷った場面です。また、種目を調べ直して情報がばらばらで混乱したときや、「この種目は本当に自分に合っているのか」と不安になったときにも思い出してもらえると考えます。
- それを置き換えてまで使う理由はあるか？
  ・理由はあると考えます。仕事後の限られた時間と気力の中で、調べ直す手間をなくし、「理由が分かる」ことで納得して迷わずトレーニングできるからです。ただし、既存の情報源を完全に置き換えるのではなく、まずは「種目を選ぶ場面」でこのアプリを使ってもらうことを目指します。


## 4-4. ユーザーがサービスを導入して利用するまでのイメージ(導入・継続の流れ)

きっかけ(知る・思い出す場面)
30代になって体の衰えを感じ、「何とかしなければ」と筋トレを始めたものの、種目選びに迷ったり、調べるたびに違う情報が出て混乱したりした場面がきっかけです。【SNSや検索で「筋トレ 種目 選び方」などを調べたときに、このアプリを知る】ことを想定しています。その後は、仕事後にトレーニングを始める前の「今日は何をやろうか」と迷う場面で思い出してもらいます。

最初の一歩(登録・導入)
負担を最小限にするため、最初の操作は【鍛えたい部位(胸・背中・脚など)を選ぶ】だけにします。長い会員登録や細かい設定は後回しにして、選んだ直後に「おすすめ種目」と「なぜその種目が良いのか」がすぐ見られる形にします。仕事後の疲れた状態でも、数十秒で価値を感じられることを目指します。

続ける理由(習慣・必要性・価値)
続けてもらう理由は3つあると考えます。

必要性: トレーニングのたびに「何をやるか」を決める必要があり、そのたびに使う場面が生まれる。
価値: 理由が分かることで、毎回迷わず納得してトレーニングでき、時間と気力の節約になる。
習慣化: 【トレーニング内容の記録や、前回の続きから始められる機能】により、「アプリを開けば今日やることが決まる」状態を作る。

このように、「仕事後に開く→迷わず決まる→納得してやり切る」という流れを繰り返し体験できることが、継続につながると考えます。

### 5-2. それでも自分が作りたい理由

私自身、トレーニングを「ただこなすだけ」の作業にしてしまった経験があります。もっと鍛えたい部位を【YouTube・検索サイト・トレーニングアプリなど】で調べると、おすすめの種目はすぐ見つかりました。しかし、「なぜその種目が良いのか」まで説明されていることはほとんどありませんでした。

例えば、胸を鍛えたくて調べたところ、ベンチプレスとダンベルフライの両方が紹介されていました。どちらを選ぶべきか、それぞれ胸のどこに効くのかが分からず、判断できませんでした。しかも、調べ直すたびに別の種目が出てきて、結局何をすればよいのか分からなくなってしまいました。

既存のサービスは「何をやるか」は教えてくれますが、「なぜそれをやるのか」という納得感までは得られませんでした。ここに、私は物足りなさと違和感を覚えました。

トレーニングの意味を理解できれば、鍛えたい筋肉を意識しながら動かせるようになり、種目選びにも迷わなくなると考えています。その結果、トレーニングを続けやすくなるはずです。そこで、種目ごとの「理由」が分かるトレーニングアプリを自分で作りたいと思いました。

### 10-3.キャッチアップ不足の懸念

キャッチアップ不足の段階では以下の懸念点があります。
1. **完成までのハードルが高い**
使用する言語やフレームワークが異なるため、キャッチアップにかかる時間は個人差があるものの、一定の時間を要することが予想されます。
2. **Issueの見積もりが難しい**
「どこまで理解していて、何が分からないのか」「調査にかかる時間」などが不明瞭な場合、開発期間内に完了することが難しくなってしまいます。

例えば、最近注目されているReactやNextについて。
Reactについては**本リリース後に組み込む方向で検討**するのが良いかと考えています。
その後、React単体のキャッチアップを行い、アプリに組み込む技術的な検証をした上で、組み込むかどうかを判断する形が理想かもしれません。
